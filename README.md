## What it does

`main.ts` (Node 22, no dependencies, no network) writes one single-line
joke about office life — 90 characters — deterministically to
`/output/entry.txt`:

> The office printer only jams when the document is urgent, which is how I know it can read.

The setup names a concrete office object misbehaving with suspicious
timing; the punchline flips it — a jam is not bad luck, it is proof the
machine is reading the queue. One sentence, plain words, nothing to
explain.

## Run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (creating `/output` if needed).
